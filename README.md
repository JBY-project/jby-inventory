# Jeff Brown Yachts — Inventory Page

The yachts-for-sale catalogue: the filter row, the grid of listing cards,
sorting and pagination.

Live build: https://jby-project.github.io/jby-inventory/

---

## Contents

```
index.html                  the page, generated by tools/build_index.py
jby-system.css              the site's tokens and base type
assets/css/
  yacht_catalog.css         the deployed catalogue's own sheet
  yacht_style.css           ditto
  custom_yacht_style.css    ditto — the filter panels live here
  jby-chrome.css            the prototype chrome that replaces the deployed
                            header and footer, plus this page's overrides
  vessel-card.css           the listing card, lifted from the home page
  filter-sheet.css          the filter and sort panels as bottom sheets,
                            below 760px
  fonts.css                 Mesmerize + Myriad Pro
  contact-expert-modal.css
  header-v2-mega-menu.css, jby-search.css, jby-search-mobile.css,
  site-shell-approved.css
assets/js/
  listings.js               the fleet, as data
  inventory.js              the shim that answers the two endpoints the
                            catalogue fetches, and everything this page does
                            that the deployed one could not be asked
  yacht_catalog.js          the deployed catalogue's own script
  band.js, contact-expert-modal.js, header-v2-drilldown.js,
  yacht-card-hover.js

```

## On a phone

Below 760px the six filter panels and the sort menu are bottom sheets — full
width, at most 86% of the screen, the title bar and the Clear/Apply bar pinned
at either end. They close by their ✕, by a choice, or by the veil behind them.
Make or Model goes one level in: the makes step aside and the ranges take the
sheet, with the way back in the title bar. Above 760px every panel is the
dropdown it was.
